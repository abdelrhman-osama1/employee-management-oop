# Employee Hierarchy & Payroll Demo (OOP in C#)

A focused console application demonstrating core **Object-Oriented Programming (OOP)** concepts in C#, specifically inheritance, method overriding, and polymorphic behavior.

## Core Concepts Demonstrated
- **Inheritance:** Derived class `Manager` extending the base class `Employee`.
- **Polymorphism:** Utilizing `virtual` and `override` on the `Work()` method to execute specialized behavior dynamically.
- **Base Constructor Chaining:** Reusing parent initialization via the `base()` keyword.
- **Generic Collections:** Storing and iterating over base-type collections (`List<Employee>`) containing mixed derived objects.

## Tech Stack
- **Language:** C# (.NET)
- **Paradigm:** Object-Oriented Programming
